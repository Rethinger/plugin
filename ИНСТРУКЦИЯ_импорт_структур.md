# ИНСТРУКЦИЯ: импорт и размещение структур для плагина «Мммм»

Версия: 1.0
Дата: 2025-10-19

Эта инструкция описывает, как подготовить и импортировать структуры, используемые плагином, и какие требования к якорным точкам и именам регионов.

## 1. Форматы структур

Рекомендуемый формат: `.schem` (WorldEdit 1.13+). Допустимы также `.schematic` и структуру-блоки (`.nbt`) — при наличии соответствующей интеграции. По умолчанию предполагается WorldEdit.

## 2. Список требуемых структур

- forgotten_altar — «Забытый Алтарь» (Акт 1)
- crossroads_node — «Узел Перекрёстков» (Акт 1)
- boss1_summon_site — «Площадка призыва Босса №1» (Ад)
- boss2_summon_site — «Площадка призыва Босса №2» (Ад)
- end_final_shrine — «Финальная структура с 5 сундуками» (Эндер)
- overworld_awakened_portal — «Портал в Верхнем мире после Босса №2»

Имена использовать строго как указано (настраиваемо через `structures.yml`).

## 3. Якорные точки и маркеры

Внутри каждой структуры разместите маркеры (armor stand с именем-меткой или блоки-«сиды») для привязки логики:

- marker:interact — точка взаимодействия игрока (например, плита у Алтаря).
- marker:spawn_boss — точка спавна босса.
- marker:chests[1..5] — сундуки для финала (точная нумерация обязательна).
- marker:portal_origin — центр портала (для Overworld портала и финального портала).

Если маркеры реализуются через специальные блоки, используйте, например, резные тыквы или рамки с картой и подписью табличкой рядом (плагин распознаёт по табличке `[marker:name]`).

## 4. Ориентация и высота

- Каждая структура должна иметь нулевую точку внизу по центру (Y — нижняя плоскость), чтобы корректно вставляться на неровный рельеф.
- Для адских структур учитывать базальтовые дельты/лаву: обеспечить опорную платформу достаточной толщины.

## 5. Рекомендации по размеру

- Алтари/узлы: до 25×25×20 блоков.
- Площадки босса: до 40×40×25.
- Финальная структура: до 31×31×20 (вписывается в арену конца без пересечения с яйцом).
- Overworld портал: портал сам генерируется плагином; структура-окружение до 21×21×15.

## 6. Размещение файлов

Положите файлы в папку плагина:
```
plugins/StoryMmmm/structures/
  forgotten_altar.schem
  crossroads_node.schem
  boss1_summon_site.schem
  boss2_summon_site.schem
  end_final_shrine.schem
  overworld_awakened_portal.schem
```

Путь настраивается через `structures.yml`.

## 7. Конфигурация `structures.yml`

Пример:
```yaml
version: 1
provider: worldedit # worldedit|internal
files:
  forgotten_altar: "structures/forgotten_altar.schem"
  crossroads_node: "structures/crossroads_node.schem"
  boss1_summon_site: "structures/boss1_summon_site.schem"
  boss2_summon_site: "structures/boss2_summon_site.schem"
  end_final_shrine: "structures/end_final_shrine.schem"
  overworld_awakened_portal: "structures/overworld_awakened_portal.schem"
markers:
  useArmorStand: true
  useSigns: true
  chestNames: ["marker:chests1","marker:chests2","marker:chests3","marker:chests4","marker:chests5"]
placement:
  netherBoss2SearchRadius: 500
  overworldPortalDistanceFromSpawn: 500
safety:
  replaceLiquidsWith: "BASALT"
  fillUnderStructureDepth: 2
```

## 8. Проверка

- Включите режим отладки `/story tp <structure>` для предпросмотра всех структур.
- Команда `/story reset world` удаляет размещённые структуры и порталы (для тестирования повторной генерации).

## 9. Частые проблемы

- Неверные имена файлов — структура не найдена.
- Отсутствуют маркеры — логика (сундуки/точки спавна) не привязывается.
- Вставка над лавой — включите `safety.replaceLiquidsWith` и `fillUnderStructureDepth`.
