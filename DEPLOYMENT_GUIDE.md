```bash
# Создайте бэкап старой версии (если обновляете):
```

## Детальная инструкция

### 1. Требования

**Сервер**:
- Paper/Spigot 1.21.4 или выше
- Java 21+
- Минимум 2GB RAM

**Зависимости**:
- Adventure API (включена в Paper)
- Нет дополнительных плагинов

### 2. Первая установка

#### 2.1. Копирование файла
```bash
cd /path/to/your/server
cp /path/to/story-plugin-1.0.0.jar plugins/
```

#### 2.2. Запуск сервера
Сервер автоматически создаст:
```
plugins/MmmmStoryPlugin/
├── config.yml           # Основная конфигурация
├── dialogs.yml          # Русские диалоги
├── dialogs_en.yml       # English dialogs
├── sounds.yml           # Звуки
├── messages_ru.yml      # Системные сообщения
└── data/                # Папка для данных игроков
    └── players/         # Настройки игроков (создаётся автоматически)
```

#### 2.3. Проверка в игре
```
# Зайдите на сервер как админ
/story settings   # Откроется меню настроек
```

### 3. Обновление существующего плагина

#### 3.1. Резервное копирование
```bash
# Остановите сервер!
cd /path/to/your/server/plugins

# Бэкап JAR
mkdir -p backups
cp story-plugin-*.jar backups/story-plugin-$(date +%Y%m%d).jar

# Бэкап данных
cp -r MmmmStoryPlugin/ backups/MmmmStoryPlugin-$(date +%Y%m%d)/
```

#### 3.2. Замена файла
```bash
# Удалите старую версию
rm story-plugin-*.jar

# Скопируйте новую
cp /path/to/new/story-plugin-1.0.0.jar .
```

#### 3.3. Обновление конфигураций
```bash
# Если нужно добавить новые файлы:
# Удалите старые dialogs_en.yml чтобы создался новый:
rm MmmmStoryPlugin/dialogs_en.yml

# При запуске плагин создаст обновлённую версию
```

#### 3.4. Миграция данных
```bash
# Настройки игроков в папке data/players/ сохраняются автоматически
# Никаких дополнительных действий не требуется
```

### 4. Конфигурация после установки

#### 4.1. Проверка config.yml
```yaml
# plugins/MmmmStoryPlugin/config.yml
plugin:
  version: "1.0.0"
  debug: false

campaign:
  enabled: true
  # ... остальные настройки
```

#### 4.2. Проверка прав доступа
```yaml
# Убедитесь что права настроены:
# permissions.yml или LuckPerms:

story.start: op        # Только админы могут запускать кампанию
story.settings: true   # Все игроки могут настраивать параметры
```

### 5. Тестирование

#### Базовый тест (1 игрок)
```
1. /story settings
2. Изменить все настройки
3. Подтвердить
4. Релог
5. /story settings снова
6. Проверить что настройки сохранились
```

#### Расширенный тест (2+ игрока)
```
1. Удалить data/players/*.yml
2. Админ: /story start
3. Всем игрокам открывается меню
4. Каждый настраивает свои параметры
5. Подтвердить у всех
6. Кампания запускается
```

### 6. Откат при проблемах

#### Быстрый откат
```bash
# Остановите сервер
cd /path/to/your/server/plugins

# Восстановите бэкап
rm story-plugin-1.0.0.jar
cp backups/story-plugin-YYYYMMDD.jar .

# Восстановите данные если нужно
rm -rf MmmmStoryPlugin/
cp -r backups/MmmmStoryPlugin-YYYYMMDD/ MmmmStoryPlugin/

# Запустите сервер
```

### 7. Мониторинг

#### Логи сервера
```bash
# Проверьте логи на ошибки:
tail -f logs/latest.log | grep -i "story\|error\|exception"
```

#### Проверка данных
```bash
# Папка игроков должна создаваться:
ls -la plugins/MmmmStoryPlugin/data/players/

# Файлы настроек игроков (UUID.yml):
cat plugins/MmmmStoryPlugin/data/players/<UUID>.yml
```

### 8. Частые проблемы

#### Проблема: "Plugin failed to enable"
**Решение**:
- Проверьте версию Java (должна быть 21+)
- Проверьте версию Paper (1.21.4+)
- Проверьте логи на конкретную ошибку

#### Проблема: "Dialog not found"
**Решение**:
- Убедитесь что dialogs.yml и dialogs_en.yml существуют
- Проверьте что файлы в правильном формате YAML
- Проверьте что ключи диалогов правильные

#### Проблема: Меню не открывается
**Решение**:
- Проверьте права доступа: `story.settings`
- Проверьте что SettingsManager инициализирован (логи)
- Попробуйте `/story menu` (алиас)

#### Проблема: Настройки не сохраняются
**Решение**:
- Проверьте что папка `data/players/` существует
- Проверьте права доступа к папке (запись)
- Проверьте логи на ошибки записи в YAML
