# Последние изменения плагина

## Версия 1.0.0 - Обновление функционала

### ✅ Добавлено

#### 1. Команда выдачи предметов `/story give`
- Использование: `/story give <игрок> <предмет>`
- Права: `story.admin`
- Поддерживаемые предметы и их алиасы:
  - `stabilization_core`, `core` - Ядро стабилизации
  - `boss1_key`, `boss1`, `boss1_summon_key` - Ключ призыва Босса 1
  - `boss2_key`, `boss2`, `boss2_summon_key` - Ключ призыва Босса 2
  - `portal_key` - Ключ портала
  - `artifact_1`, `artifact_2`, `artifact_3`, `artifact_4`, `artifact_5` - Артефакты

**Пример:** `/story give Steve boss1_key`

---

#### 2. Улучшенная механика волн скелетов (Акт 1)

**Изменения:**
- ✅ **Непрерывный спавн**: Скелеты теперь спавнятся на протяжении всей ночи, а не только в начале
- ✅ **Умная генерация**: Система проверяет количество скелетов рядом с игроком и добавляет по 3 новых каждые 5 секунд (максимум 15)
- ✅ **Радиус агрессии 75 блоков**: Воины-скелеты автоматически атакуют ближайших игроков в радиусе 75 блоков
- ✅ **Достижение после волны**: При наступлении дня игроки, пережившие ночь, получают достижение `survived_skeleton_wave`

**Механика:**
1. Каждую 3-ю ночь начинается волна
2. Игрок видит предупреждение: "§c§lВолна скелетов началась! Защищайтесь до рассвета!"
3. Скелеты спавнятся постепенно всю ночь (13000-23000 тиков)
4. Каждый скелет получает таргет - ближайшего игрока
5. На рассвете выжившие игроки получают достижение

---

#### 3. Сообщения только в чате

**Изменено:** Все диалоги теперь отображаются только в чате, без actionbar и title-экранов.

**Затронутые системы:**
- Диалоги NPC
- Системные сообщения
- Уведомления о событиях

---

#### 4. Тестовые структуры

Добавлены полноценные тестовые структуры для отладки:

**Доступные структуры:**

1. **forgotten_altar** - Забытый алтарь (Акт 1)
   - Платформа 7x7 из каменных кирпичей
   - Центральный алтарь 3x3x2
   - Золотой блок в центре
   - 4 угловых пилона
   - Табличка с описанием

2. **crossroads_node** - Узел перекрёстка (Акт 1)
   - Платформа 5x5 из замшелого булыжника
   - Обсидиановый столб с алмазным блоком
   - 4 светокаменных маркера направлений
   - Табличка с описанием

3. **boss1_arena** - Арена Босса 1 (Акт 2)
   - Платформа 15x15 из чернита
   - Стены из полированных чернитовых кирпичей
   - Пилон призыва из незеритовых блоков
   - Табличка "БОСС 1"

4. **boss2_arena** - Арена Босса 2 (Акт 3)
   - Платформа 20x20 из эндерняка
   - Центральный обсидиановый столб с яйцом дракона
   - 4 угловых пурпурных пилона с энд-стержнями
   - Табличка "БОСС 2"

5. **end_portal_frame** - Рамка портала Края (Акт 5)
   - Платформа из кирпичей эндерняка
   - Рамка портала 3x3
   - Маяк в центре
   - Табличка "ПОРТАЛ"

**Использование:**
```
/story tp altar      - Телепорт на алтарь (автосоздание)
/story tp node       - Телепорт на узел (автосоздание)
/story tp boss1      - Телепорт на арену Босса 1
/story tp boss2      - Телепорт на арену Босса 2
```

### 🔧 Технические улучшения

1. **Act1Listener.java**
   - Переработана логика `startSkeletonWaveTask()`
   - Добавлен метод `spawnSkeletonWavesForPlayer()` с умным контролем количества мобов
   - Реализована система агрессии с радиусом 75 блоков
   - Добавлено сохранение достижений через `DataManager`

2. **DialogManager.java**
   - Упрощена логика отображения сообщений
   - Удалены actionbar и title режимы
   - Все сообщения теперь только в чате

3. **StructureManager.java**
   - Добавлены методы генерации 5 типов структур
   - Полная генерация блоков с табличками
   - Использование различных материалов для каждого типа

4. **StoryCommand.java**
   - Добавлен метод `handleGive()` с полной валидацией
   - Поддержка алиасов предметов
   - Автодополнение для имён игроков и типов предметов

5. **DataManager.java**
   - Метод `addPlayerAchievement()` уже существовал и используется для сохранения достижений

### 📋 Команды

Полный список команд:
- `/story start` - Начать сюжет
- `/story skip <акт>` - Пропустить до акта
- `/story reset` - Сбросить прогресс
- `/story progress` - Показать прогресс
- `/story tp <локация>` - Телепорт
- `/story reload` - Перезагрузить конфигурацию
- `/story give <игрок> <предмет>` - Выдать предмет *(НОВОЕ)*

---

### 🎮 Для администраторов

**Настройка волн скелетов** (`config.yml`):
```yaml
acts:
  skeletonWaves:
    perPlayerRadius: 75      # Радиус спавна и агрессии
    maxPerPlayer: 15         # Максимум скелетов на игрока
```

**Выдача предметов через команду:**
```
/story give @a stabilization_core  - Всем игрокам ядро
/story give Steve boss1            - Steve ключ босса 1
/story give Notch artifact_3       - Notch артефакт №3
```

**Создание тестовых структур:**
1. Используйте `/story tp <структура>` для автоматического создания
2. Или вручную через команды плагина генерации структур
