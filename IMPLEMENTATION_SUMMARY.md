# Система персональных настроек - Итоговое резюме

## 🎯 Что было реализовано

### Новые классы

#### 1. **PlayerSettings.java**
- Хранит 3 настройки игрока:
  - `showDialogs: boolean` - показывать диалоги
  - `language: String` - язык ("ru" или "en")
  - `dialogSpeed: DialogSpeed` - скорость (SLOW/NORMAL/FAST)
- Enum `DialogSpeed` с множителями:
  - SLOW = 1.5 (медленнее на 50%)
  - NORMAL = 1.0 (обычная)
  - FAST = 0.75 (быстрее на 25%)

#### 2. **SettingsManager.java**
- GUI меню с 27 слотами
- Интерактивные кнопки:
  - Слот 11: Показ диалогов (Книга/Барьер)
  - Слот 13: Язык (Баннер RU/EN)
  - Слот 15: Скорость (Яйцо/Часы/Перо)
  - Слот 22: Подтвердить (Зелёная шерсть)
- Система ожидания игроков:
  - Async проверка каждую секунду
  - Action bar с индикацией прогресса
  - Автозапуск когда все готовы

### Изменённые классы

#### 3. **ConfigManager.java**
- Добавлено поле `Map<String, FileConfiguration> dialogsByLanguage`
- Загрузка `dialogs_en.yml` при старте
- Новый метод `getDialogs(String language)` для получения локализации

#### 4. **DialogManager.java**
- **playAutomaticDialog()** теперь:
  - Загружает настройки игрока
  - Пропускает диалог если `showDialogs = false`
  - Получает диалоги на нужном языке
  - Применяет `speedMultiplier` к задержкам
- **playDialogForAll()** упрощён:
  - Вызывает `playDialog()` для каждого игрока
  - Каждый игрок получает персонализированный опыт

#### 5. **DataManager.java**
- Методы для работы с настройками:
  - `getPlayerSettings(UUID)` - загрузка с дефолтами
  - `savePlayerSettings(UUID, PlayerSettings)` - сохранение
  - `hasConfiguredSettings(UUID)` - проверка первого запуска
  - `markSettingsConfigured(UUID)` - пометка настроенности

#### 6. **StoryCommand.java**
- Добавлены команды: `/story settings`, `/story menu`
- Метод `handleSettings(CommandSender)` для открытия GUI
- `handleStart()` вызывает `startCampaignWithSettings()` вместо прямого старта
- Обновлена справка и автодополнение

#### 7. **MmmmStoryPlugin.java**
- Добавлено поле `SettingsManager settingsManager`
- Инициализация и регистрация менеджера
- Добавлен геттер `getSettingsManager()`

### Новые ресурсы

## 🎮 Как работает система

### Первый запуск кампании
```
Admin: /story start
↓
Система проверяет настройки всех игроков
↓
Открывает меню для игроков без настроек
↓
Ждёт пока все настроят параметры
↓
Каждую секунду проверяет готовность (async task)
↓
Action bar: "⏳ Ожидание... (X осталось)"
↓
Все готовы → Объявление → Старт через 2 сек
↓
Кампания начинается!
```

### Во время игры
```
Диалог для всех игроков
↓
playDialogForAll(dialogKey)
↓
Для каждого игрока:
  ├─ Загрузить настройки (DataManager)
  ├─ Проверить showDialogs
  ├─ Если false → пропустить
  ├─ Если true:
  │  ├─ Получить диалог на языке игрока
  │  ├─ Применить speedMultiplier
  │  └─ Показать с задержками
  └─ Следующий игрок
```

### Пример персонализации
```
3 игрока на сервере:

Игрок А (RU, FAST, Включено):
├─ Видит русские диалоги
├─ Задержки × 0.75
└─ Быстрое чтение

Игрок Б (EN, SLOW, Включено):
├─ Видит английские диалоги
├─ Задержки × 1.5
└─ Медленное чтение

Игрок В (RU, -, Выключено):
├─ НЕ видит диалоги
├─ Фокус на геймплее
└─ Звуки и эффекты остаются
```
