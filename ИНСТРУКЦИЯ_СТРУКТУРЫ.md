## 🛠️ КАК СОЗДАТЬ СТРУКТУРУ

### Способ 1: Structure Block (в игре)

1. Получите блок структуры: `/give @s structure_block`
2. Постройте вашу структуру
3. Поставьте Structure Block в углу структуры
4. Выберите режим **SAVE**
5. Укажите размеры (X, Y, Z)
6. Введите имя структуры
7. Нажмите **SAVE**
8. Структура сохранится в `.minecraft/saves/<world>/generated/minecraft/structures/`

### Способ 2: WorldEdit

1. Выделите область структуры: `//wand`
2. Сохраните: `//copy`
3. Экспортируйте в .nbt: `//schem save <имя>`
4. Структура сохранится в `plugins/WorldEdit/schematics/`

## 📐 РЕКОМЕНДУЕМЫЕ РАЗМЕРЫ СТРУКТУР

### 1. Forgotten Altar (Забытый Алтарь)
- **Размер:** 11x7x11 блоков
- **Центральный блок:** Постамент для Ядра
- **Описание:** Древние руины с фиолетовым свечением
- **Блоки:**
  - Каменный кирпич (трещины)
  - Фиолетовые стекла
  - Светокамень (под блоками)
  - Постамент (3 блока вверх)
  - Декор: цветы, лианы

### 2. Crossroads Node (Узел Перекрёстков)
- **Размер:** 9x5x9 блоков
- **Центральный блок:** Постамент для Ядра
- **Описание:** Круговая платформа с рунами
- **Блоки:**
  - Обсидиан (основа)
  - Светящийся камень
  - Незеритовые блоки (руны)
  - Постамент (5 блоков вверх)

### 3. Boss1 Altar (Алтарь Повелителя)
- **Размер:** 15x8x15 блоков
- **Центральный блок:** Алтарь призыва
- **Описание:** Мрачная арена с черепами
- **Блоки:**
  - Адский кирпич
  - Черепа скелетов (декор)
  - Красная терракота (руны)
  - Алтарь (незеритовый блок)
  - Кольцо огня (netherack)

### 4. Boss2 Structure (Структура Изверга)
- **Размер:** 21x10x21 блоков
- **Центральный блок:** Лавовый алтарь
- **Описание:** Адская арена с лавой
- **Блоки:**
  - Базальт (основа)
  - Лава (по краям)
  - Магматические блоки
  - Алтарь (адский блок)
  - Факелы душ

### 5. End Ritual Structure (Структура Ритуала)
- **Размер:** 19x12x19 блоков
- **Центральные элементы:** 5 постаментов по кругу
- **Описание:** Пять башен элементов вокруг центра
- **Блоки:**
  - Камень Края (основа)
  - Пурпурные блоки
  - 5 постаментов (по 4 блока высотой)
  - Центральная платформа
  - Стержни Края (декор)

## 🔧 КОНФИГУРАЦИЯ В config.yml

```yaml
structures:
  forgotten_altar:
    enabled: true
    file: "forgotten_altar.nbt"
    spawn_distance_from_player: 500  # блоков от точки появления игрока
    direction: "NORTH"  # направление от спавна
    marker_particle: "PORTAL"
    marker_duration: 6000  # тики (5 минут)
    
  crossroads_node:
    enabled: true
    file: "crossroads_node.nbt"
    spawn_distance_from_player: 750
    direction: "SOUTH"
    marker_particle: "ENCHANTING_TABLE"
    marker_duration: 6000
    
  boss1_altar:
    enabled: true
    file: "boss1_altar.nbt"
    nether_only: true  # только в Аду
    spawn_after_event: "crossroads_activated"
    search_radius: 500  # поиск подходящего места
    marker_particle: "SOUL"
    
  boss2_structure:
    enabled: true
    file: "boss2_structure.nbt"
    nether_only: true
    spawn_after_event: "boss1_defeated"
    spawn_distance_from_boss1: 500
    marker_particle: "LAVA"
    
  end_ritual_structure:
    enabled: true
    file: "end_ritual_structure.nbt"
    end_only: true
    replace_end_portal: true  # заменяет портал после победы над драконом
    marker_particle: "END_ROD"
```

### Шаг 1: Подготовка файлов
```bash
# Скопируйте .nbt файлы в папку
cp *.nbt plugin/src/main/resources/structures/
```

### Шаг 2: Перекомпилируйте плагин
```bash
cd plugin
mvn clean package
```

## ⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ

### Что НЕ включать в структуры:

1. ❌ Мобов (спавнятся через код)
2. ❌ Сундуки с лутом (генерируются плагином)
3. ❌ Сложные NBT данные (книги, таблички с текстом)
4. ❌ Command blocks (не нужны)
5. ❌ Слишком много жидкостей (лаг)

### Что ОБЯЗАТЕЛЬНО включать:

1. ✅ Центральный блок (плагин ищет его)
2. ✅ Освещение (предотвращает спавн мобов)
3. ✅ Прочные блоки (не ломаются случайно)
4. ✅ Декоративные элементы (атмосфера)
5. ✅ Площадку для боя (для boss-структур)

## 🔄 ОБНОВЛЕНИЕ СТРУКТУР

### Если нужно изменить структуру:

1. Измените .nbt файл
2. Замените в `src/main/resources/structures/`
3. Перекомпилируйте плагин
4. Перезапустите сервер
5. Используйте `/story reload` для применения изменений

### Для активных серверов:

```bash
# Команда для замены уже сгенерированных структур
/story regenerate_structure <type>

# Очистка старых структур перед перегенерацией
/story clear_structure <type>
```

## 📞 ПОДДЕРЖКА

### Если структуры не загружаются:

1. Проверьте логи: `logs/latest.log`
2. Убедитесь, что .nbt файлы в правильной папке
3. Проверьте config.yml на ошибки
4. Используйте `/story debug structures`

### Сообщения об ошибках:

```
[ERROR] Structure file not found: forgotten_altar.nbt
[ERROR] Invalid structure format: crossroads_node.nbt
[ERROR] Failed to place structure: boss1_altar (out of world)
```
