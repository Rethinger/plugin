# ✅ Чеклист тестирования системы настроек

## Подготовка к тестированию

### Установка
- [ ] Скопировать `story-plugin-1.0.0.jar` в папку `plugins/`
- [ ] Запустить сервер
- [ ] Убедиться что плагин загрузился без ошибок
- [ ] Проверить что создалась папка `plugins/MmmmStoryPlugin/`

### Проверка файлов
- [ ] Файл `dialogs.yml` создан
- [ ] Файл `dialogs_en.yml` создан
- [ ] Папка `data/players/` создалась

## Тестирование меню настроек

### Открытие меню
- [ ] Команда `/story settings` работает
- [ ] Команда `/story menu` работает (алиас)
- [ ] Меню открывается с 27 слотами
- [ ] Видны 4 кнопки на правильных позициях

### Настройка: Показ диалогов (Слот 11)
- [ ] По умолчанию: Книга с зелёным названием "Показывать"
- [ ] Клик → переключается на Барьер "Скрыть" (красный)
- [ ] Ещё клик → обратно на Книгу "Показывать"
- [ ] Описание предмета корректное

### Настройка: Язык (Слот 13)
- [ ] По умолчанию: Фиолетовый баннер "Русский"
- [ ] Клик → Голубой баннер "English"
- [ ] Ещё клик → обратно "Русский"
- [ ] Описание корректное на обоих языках

### Настройка: Скорость (Слот 15)
- [ ] По умолчанию: Часы "Обычная скорость"
- [ ] Клик → Перо "Быстрая скорость"
- [ ] Ещё клик → Яйцо черепахи "Медленная скорость"
- [ ] Ещё клик → обратно Часы "Обычная"
- [ ] Описание с процентами корректное

### Подтверждение (Слот 22)
- [ ] Зелёная шерсть "ПОДТВЕРДИТЬ"
- [ ] Клик → меню закрывается
- [ ] Сообщение "Настройки сохранены!" появляется
- [ ] Звук подтверждения проигрывается

## Тестирование сохранения

### Создание настроек
- [ ] Настроить параметры в меню
- [ ] Подтвердить
- [ ] Файл `data/players/<UUID>.yml` создан
- [ ] В файле правильные значения:
  - [ ] `settings.showDialogs`
  - [ ] `settings.language`
  - [ ] `settings.dialogSpeed`
  - [ ] `configured: true`

### Сохранение после релога
- [ ] Выйти с сервера
- [ ] Зайти снова
- [ ] Открыть `/story settings`
- [ ] Настройки остались те же что были

## Тестирование диалогов

### Русский язык
- [ ] Установить язык "Русский"
- [ ] Запустить любой диалог
- [ ] Текст на русском языке
- [ ] Форматирование корректное

### English
- [ ] Установить язык "English"
- [ ] Запустить тот же диалог
- [ ] Текст на английском языке
- [ ] Форматирование корректное
- [ ] Нет "key not found" ошибок

### Скорость: Медленная (SLOW)
- [ ] Установить скорость "Медленная"
- [ ] Запустить диалог с delay: 4 секунды
- [ ] Реальная задержка ≈ 6 секунд (4 × 1.5)

### Скорость: Обычная (NORMAL)
- [ ] Установить скорость "Обычная"
- [ ] Запустить тот же диалог
- [ ] Реальная задержка ≈ 4 секунды (4 × 1.0)

### Скорость: Быстрая (FAST)
- [ ] Установить скорость "Быстрая"
- [ ] Запустить тот же диалог
- [ ] Реальная задержка ≈ 3 секунды (4 × 0.75)

### Отключение диалогов
- [ ] Установить "Скрыть" диалоги
- [ ] Запустить любой диалог
- [ ] Диалоги НЕ появляются в чате
- [ ] Звуки могут проигрываться (опционально)
- [ ] Эффекты применяются (если есть)

## Мультиплеер тестирование (2+ игрока)

### Индивидуальные настройки
- [ ] Игрок 1: Русский, Быстрая
- [ ] Игрок 2: English, Медленная
- [ ] Запустить `/story start` от админа
- [ ] Оба игрока получают меню настроек
- [ ] Каждый настраивает свои предпочтения

### Система ожидания
- [ ] Action bar показывает "⏳ Ожидание... (X осталось)"
- [ ] Счётчик уменьшается когда игроки подтверждают
- [ ] Когда все подтвердили:
  - [ ] Появляется "✦ ВСЕ ИГРОКИ ГОТОВЫ! ✦"
  - [ ] "Кампания начнётся через 2 секунды..."
  - [ ] Через 2 секунды запускается

### Персональный опыт
- [ ] Игрок 1 видит русские диалоги быстро
- [ ] Игрок 2 видит английские диалоги медленно
- [ ] Задержки разные для каждого игрока
- [ ] Если Игрок 3 отключил диалоги - не видит их

## Тест команды /story start

### С не настроенными игроками
- [ ] Удалить файлы `data/players/*.yml`
- [ ] Админ: `/story start`
- [ ] Всем игрокам открылось меню настроек
- [ ] Сообщение "⚙ НАСТРОЙКА КАМПАНИИ"

### С уже настроенными
- [ ] Все игроки настроены (файлы существуют)
- [ ] Админ: `/story start`
- [ ] Кампания начинается сразу
- [ ] Меню НЕ открывается

### Смешанный сценарий
- [ ] 2 игрока настроены, 1 новый
- [ ] Админ: `/story start`
- [ ] Только новому открывается меню
- [ ] Остальные ждут

## Граничные случаи

### Закрытие меню без подтверждения
- [ ] Открыть меню
- [ ] Изменить настройки
- [ ] Закрыть меню (ESC) БЕЗ подтверждения
- [ ] Открыть снова
- [ ] Настройки НЕ сохранились

### Изменение настроек во время кампании
- [ ] Начать кампанию
- [ ] Во время игры: `/story settings`
- [ ] Изменить язык
- [ ] Подтвердить
- [ ] Следующий диалог на новом языке

### Несуществующий ключ диалога
- [ ] Вызвать диалог с несуществующим ключом
- [ ] В логах warning "Dialog not found"
- [ ] Сервер не крашится

### Отсутствие английского перевода
- [ ] Установить English
- [ ] Вызвать диалог который не переведён
- [ ] Проверить логи на warning
- [ ] Или показывается русская версия (fallback)
