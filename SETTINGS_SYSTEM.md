# Система персональных настроек игрока

## Обзор

Плагин теперь поддерживает персональные настройки для каждого игрока, включая:
- **Показ диалогов** - включить/выключить диалоги основного сюжета
- **Язык диалогов** - Русский или English
- **Скорость диалогов** - Медленная (1.5x), Обычная (1.0x), Быстрая (0.75x)

## Команды

### Для игроков
- `/story settings` или `/story menu` - Открыть меню настроек
- Настройки можно изменять в любое время во время игры

### Для администраторов
- `/story start` - Начать кампанию (автоматически откроет меню настроек для всех игроков, которые ещё не настроили свои предпочтения)

## Как работает система

### 1. Первый запуск кампании
Когда администратор вводит `/story start`:
1. Система проверяет, какие игроки ещё не настроили свои предпочтения
2. Автоматически открывает меню настроек для этих игроков
3. Каждую секунду проверяет готовность всех игроков
4. Когда все игроки подтвердили настройки - запускает кампанию

### 2. Меню настроек

```
║        НАСТРОЙКИ КАМПАНИИ            ║

║                                       ║
║     [🎌]  ЯЗЫК: Русский              ║
║                                       ║

║     [✔️]  ПОДТВЕРДИТЬ                ║
║                                       ║
╚═══════════════════════════════════════╝
```

**Слоты инвентаря:**
- Слот 11: Показ диалогов (Книга/Барьер)
- Слот 13: Язык (Фиолетовый/Голубой баннер)
- Слот 15: Скорость (Яйцо черепахи/Часы/Перо)
- Слот 22: Подтвердить (Зелёная шерсть)

### 3. Хранение данных

Настройки сохраняются в файлах:
```
plugins/MmmmStoryPlugin/data/players/<UUID>.yml
```

Структура файла:
```yaml
settings:
  showDialogs: true
  language: "ru"
  dialogSpeed: "NORMAL"
configured: true
```

## Технические детали

### Классы

#### PlayerSettings.java
Хранит настройки игрока:
```java
public class PlayerSettings {
    private boolean showDialogs;
    private String language;
    private DialogSpeed dialogSpeed;
    
    public enum DialogSpeed {
        SLOW(1.5),    // Медленная: +50%
        NORMAL(1.0),  // Обычная: 100%
        FAST(0.75);   // Быстрая: -25%
    }
}
```

#### SettingsManager.java
Управляет GUI и координацией игроков:
- Создание и обработка меню настроек
- Система ожидания готовности игроков
- Интеграция с DataManager для сохранения

#### DialogManager.java
Воспроизводит диалоги с учётом настроек:
```java
private void playAutomaticDialog(Player player, String dialogKey) {
    // Загрузка настроек игрока
    var settings = plugin.getDataManager().getPlayerSettings(player.getUniqueId());
    
    // Проверка: показывать ли диалоги
    if (!settings.isShowDialogs()) return;
    
    // Получение диалогов на нужном языке
    String language = settings.getLanguage();
    ConfigurationSection dialog = plugin.getConfigManager()
        .getDialogs(language)
        .getConfigurationSection(dialogKey);
    
    // Применение множителя скорости
    double speedMultiplier = settings.getSpeedMultiplier();
    int adjustedDelay = (int) (delay * speedMultiplier);
}
```

## Поведение для разных настроек

### Примеры

**Игрок А: Русский, Быстрые диалоги**
```yaml
showDialogs: true
language: "ru"
dialogSpeed: "FAST"  # 0.75x
```
- Видит диалоги на русском языке
- Задержки уменьшены на 25%

**Игрок Б: English, Медленные диалоги**
```yaml
showDialogs: true
language: "en"
dialogSpeed: "SLOW"  # 1.5x
```
- Видит диалоги на английском
- Задержки увеличены на 50%

**Игрок В: Диалоги отключены**
```yaml
showDialogs: false
language: "ru"
dialogSpeed: "NORMAL"
```
- НЕ видит никаких диалогов сюжета
- Может сосредоточиться на геймплее

   ```
   Пожалуйста, настройте ваши предпочтения перед началом.
   ```


3. **Готовность**
   ```

   Кампания начнётся через 2 секунды...
   ```

4. **Запуск**
   ```
   🎭 === КАМПАНИЯ НАЧАЛАСЬ === 🎭
   ```

## Добавление новых языков

Для добавления нового языка:

1. Создайте файл `dialogs_<код>.yml` в `src/main/resources/`
2. Скопируйте структуру из `dialogs.yml`
3. Переведите все тексты
4. Обновите `ConfigManager.loadAll()`:
   ```java
   dialogsByLanguage.put("es", loadConfig("dialogs_es.yml"));
   ```
5. Обновите GUI в `SettingsManager.createLanguageItem()`

## FAQ

**Q: Можно ли изменить настройки во время кампании?**
A: Да! Используйте `/story settings` в любое время.

**Q: Что если игрок отключил диалоги, но хочет увидеть один конкретный?**
A: Нужно временно включить диалоги в настройках.

**Q: Сохраняются ли настройки между перезапусками сервера?**
A: Да, все настройки сохраняются в YAML файлах.

**Q: Можно ли сбросить настройки игрока?**
A: Удалите файл `plugins/MmmmStoryPlugin/data/players/<UUID>.yml`
