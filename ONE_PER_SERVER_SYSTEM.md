# Обновление системы обыска - "Один предмет на сервер"

## Версия 1.1.0 - Глобальная система уникальности предметов

### 🎯 Основная концепция: ONE PER SERVER

Каждый важный предмет может быть найден **только один раз на сервере**.

---

## 📦 Система обыска по типам предметов

### 1. Ядро Стабилизации (Ruined Portal)
- **Локация**: Разрушенные порталы в Overworld
- **Шанс**: 5%
- **Время обыска**: 5-20 секунд
- **Статус**: `materials.stabilization_core_found`
- **Поведение**: После находки обыск во ВСЕХ разрушенных порталах отключается навсегда

### 2. Фрагмент Гнева (Nether Fortress)
- **Локация**: Крепости Нижнего мира
- **Шанс**: 5%
- **Время обыска**: 5-20 секунд
- **Статус**: `materials.boss1_material_found`
- **Поведение**: После находки обыск во ВСЕХ крепостях отключается
- **Сброс**: Автоматический после победы над Boss 1

### 3. Катализатор Пустоты (Bastion Remnant)
- **Локация**: Бастионы
- **Шанс**: 5%
- **Время обыска**: 5-20 секунд
- **Статус**: `materials.boss1_catalyst_found`
- **Поведение**: После находки обыск во ВСЕХ бастионах отключается
- **Сброс**: Автоматический после победы над Boss 1

### 4. Артефакты Края (End City) ⭐ НОВОЕ
- **Локация**: End City (города Края)
- **Шанс**: 10% (выше чем у обычных материалов!)
- **Время обыска**: 2-6 секунд (быстрее!)
- **Количество**: 5 уникальных артефактов
- **Статусы**:
  - `artifacts.artifact_1_found`
  - `artifacts.artifact_2_found`
  - `artifacts.artifact_3_found`
  - `artifacts.artifact_4_found`
  - `artifacts.artifact_5_found`
- **Поведение**: Каждый артефакт может быть найден только ОДИН РАЗ на сервере
- **Случайность**: При находке выбирается случайный ещё не найденный артефакт
- **Завершение**: Когда все 5 артефактов найдены, обыск в End City полностью прекращается

## 🔒 Защита от абуза

### Кулдаун между обысками
- **Время**: 5 секунд на каждый сундук
- **Сообщение**: "✗ Этот сундук уже был обыскан недавно (X сек)"
- **Предотвращает**: Многократное открытие одного сундука для фарма

### Автоматическая очистка
- Каждые 10 минут удаляются записи о сундуках, обысканных более 30 минут назад
- Позволяет повторить попытку в том же сундуке через длительное время

### Мгновенная маркировка
- Сундук помечается как "обыскиваемый" СРАЗУ при открытии
- Предотвращает дублирование запросов

## 🎮 Игровой процесс

### Обыск в End City (артефакты)

#### Открытие сундука:
```
🔍 Обыск сундука...
Искомый предмет: Артефакт Края
```

#### Во время обыска (2-6 секунд):
- Action bar: "🔍 Обыскиваю сундук..."
- Звуковые эффекты каждые 2 секунды

#### При успехе (10% шанс):
```
✓ УСПЕХ!
Артефакт Края

✓ НАЙДЕНО: Артефакт Края!
```
- Заголовок на экране
- Звук достижения
- Частицы: ENCHANT + END_ROD
- **Артефакт добавляется в сундук**

#### При неудаче (90% шанс):
```
✗ В этом сундуке ничего не найдено
```
- Можно попробовать другой сундук в другом End City
- Тот же сундук недоступен 5 секунд

#### Если все артефакты найдены:
- Обыск больше не активируется в End City
- Нет сообщений при открытии сундуков

## 🔍 Определение структур

### Ruined Portal (Overworld)
- **Блоки**: Crying Obsidian, Gold Block
- **Радиус**: 20 блоков
- **Требуется**: 5+ найденных блоков

### End City (The End)
- **Блоки**: Purpur Block, Purpur Pillar, End Stone Bricks
- **Радиус**: 30 блоков
- **Требуется**: 5+ найденных блоков
- **Особенность**: Работает в End Ships тоже!

### Nether Fortress
- **Блоки**: Nether Bricks, Nether Brick Fence
- **Радиус**: 30 блоков
- **Требуется**: 5+ найденных блоков
- **Защита**: Проверяет отсутствие Blackstone (чтобы не перепутать с Bastion)

### Bastion Remnant
- **Блоки**: Gilded Blackstone, Polished Blackstone Bricks
- **Радиус**: 30 блоков
- **Требуется**: 5+ найденных блоков
- **Приоритет**: Проверяется РАНЬШЕ Fortress

## 💾 Система сохранения

### Global Data (global.yml)

```yaml
materials:
  stabilization_core_found: false  # Ядро Стабилизации
  boss1_material_found: false      # Фрагмент Гнева
  boss1_catalyst_found: false      # Катализатор Пустоты

artifacts:
  artifact_1_found: false  # Артефакт Края №1
  artifact_2_found: false  # Артефакт Края №2
  artifact_3_found: false  # Артефакт Края №3
  artifact_4_found: false  # Артефакт Края №4
  artifact_5_found: false  # Артефакт Края №5
```

### Автосброс флагов
- **Boss 1 defeated**: Сбрасывает `boss1_material_found` и `boss1_catalyst_found`
- **Артефакты**: НЕ сбрасываются автоматически (постоянны на сервере)

## ⚙️ Технические детали

### Изменения в коде:

**ChestSpawnManager.java:**
- Добавлен `StructureType.END_CITY`
- Метод `hasUnfoundArtifacts()` - проверяет наличие незанятых артефактов
- Метод `getRandomUnfoundArtifact()` - выбирает случайный незанятый артефакт
- Обновлён `detectStructureType()` для End City
- Обновлён `markMaterialFound()` для поддержки артефактов
- Добавлен кулдаун `CHEST_COOLDOWN = 5000L` (5 секунд)
- Разные настройки для артефактов:
  - `SPAWN_CHANCE_ARTIFACT = 0.10` (10%)
  - `MIN_DELAY_ARTIFACT = 40` тиков (2 сек)
  - `MAX_DELAY_ARTIFACT = 120` тиков (6 сек)

**DataManager.java:**
- Методы `getBoolean()`, `setBoolean()` для хранения флагов
- Поддержка `artifacts.artifact_X_found`

3. **Случайный выбор**: Система сама выбирает, какой артефакт появится
