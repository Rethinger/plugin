# Proposal: Fix Boss 1 Attack Behavior

This proposal addresses several issues with Boss #1's special attack and identity, as reported by the user. The goal is to align the boss's behavior with the intended design.

The following capabilities will be modified:
- **Attack Timing**: The boss's skull attack will be re-timed to occur at the peak of its rising animation.
- **Skull Behavior**: The wither skull projectiles will be modified to prevent them from destroying blocks.
- **Naming and Loot**: The boss's name will be corrected, which will also resolve an issue preventing it from dropping the correct loot.
