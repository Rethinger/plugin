# enhance-boss1-special-attack-hemisphere

## Summary

Улучшение специальной атаки Босса №1 (Повелителя Скелетов) путем добавления новой хореографии с формированием полусферы (Hemisphere) из черепов, поднимающихся из земли, и созданием безопасных зон для игроков.

## Impact

**High** - Затрагивает ключевую механику босса, влияет на геймплей

## Why

Текущая реализация спецатаки босса №1 следует простой логике: босс поднимается в воздух, а затем на земле появляются черепа, которые летят в игроков. Это предложение полностью переделывает механику для создания более зрелищного и тактически интересного боя.

**Проблемы текущей реализации:**
- Недостаточно зрелищно для важной механики босса
- Отсутствует тактическая глубина - игроки просто уклоняются
- Низкая реиграбельность - атака предсказуема
- Нет интерактивности между фазами атаки

**Цели улучшения:**
- Создать кинематографическую и запоминающуюся спецатаку
- Добавить тактические элементы через безопасные зоны
- Увеличить вовлеченность игроков через визуальные эффекты
- Обеспечить сбалансированную сложность для разного количества игроков

## Description

### Новая механика

**Фаза 1 (Фаза черепов):**
1. **Требование волн воинов** - Босс должен вызвать минимум 2 волны воинов перед первой спецатакой (каждая волна = 2-3 воина)
2. **Ожидание после второй волны** - После 2-й волны босс ждет 12 секунд перед спецатакой (уменьшено с 15 для лучшего темпа)
3. **Заморозка призыва** - Во время спецатаки призыв воинов полностью заморожен
4. **Фаза взлета** - Босс поднимается в воздух (сохраняется текущая анимация, 1.2 секунды)
5. **Фаза ожидания** - Босс зависает в воздухе на 1 секунду
6. **Фаза формирования полусферы** - В течение 2 секунд из земли эффектно поднимаются черепа, формируя полусферу ВОКРУГ БОССА (не игрока)
7. **Фаза безопасных зон** - В процессе подъема черепов последовательно появляются безопасные зоны (количество зон = количество игроков + 1, максимум 6)
8. **Фаза финальной подготовки** - Босс ждет 1 секунду после формирования полусферы
9. **Фаза атаки** - Черепа запускаются в игроков (босс остается в воздухе)
10. **Фаза пост-атаки** - Босс зависает в воздухе 1 секунду после завершения атаки
11. **Фаза спуска** - Босс плавно спускается на землю
12. **Возобновление призыва** - После спуска на землю возобновляется призыв воинов каждые 10 секунд

**Фаза 2 (Фаза стрел):**
1. **Аналогичная механика** - Использует ту же последовательность фаз, но черепа заменены на стрелы
2. **Стрелы с мгновенным уроном** - Каждая стрела наносит ровно 1 урон (1 сердце)
3. **Игнорирование брони** - Урон стрел игнорирует броню и зачарования игроков
4. **Те же безопасные зоны** - Используется существующая система безопасных зон
5. **Босс в воздухе** - Босс также остается в воздухе во время атаки стрелами и спускается после пост-атаки
6. **Заморозка призыва** - Во время спецатаки стрелами призыв воинов также заморожен
7. **Возобновление призыва** - После спуска на землю возобновляется призыв воинов

### Тактические элементы

- **Безопасные зоны**: Игроки должны быстро определять и перемещаться в безопасные зоны
- **Визуальная индикация**: Четкая визуализация поднимающихся черепов и границ безопасных зон
- **Динамичность**: Механика заставляет игроков постоянно перемещаться и адаптироваться

## Technical Details

### Использование существующих компонентов

**Безопасные зоны:**
- Используется существующий `SafeZoneManager.java` класс
- Интеграция с существующим `SafeZone.java`
- Модификация логики создания для поддержки "игроки + 1" требования
- Сохранение существующих визуальных эффектов

**Система вызова воинов:**
- Использование существующей системы отслеживания вызовов в `BossAttackState`
- Интеграция с `recordSuccessfulWarriorSummon()`
- Проверка требования минимального количества вызовов (2+)

### Новые компоненты

- `ArrowHemisphereFormation.java` - Формирование полусферы из стрел
- `ArrowProjectile.java` - Стрелы с кастомным уроном
- `BossSpecialAttackManager.java` - Координатор с проверкой воинов

### Модифицированные компоненты

- `BossAttackState.java` - Расширен новыми фазами и проверкой воинов
- `BossRisingAnimation.java` - Поддержка новых фаз
- `WitherSkullProjectile.java` - Логика подъема из земли
- `Act2Listener.java` - Интеграция с новой системой и проверкой воинов

### Новые состояния атаки

```java
public enum SpecialAttackPhase {
    NONE,                           // Нет спецатаки
    RISING_ANIMATION,              // Босс поднимается в воздух
    HOVERING_WAIT,                 // Босс зависает в воздухе (1 сек)
    HEMISPHERE_FORMATION,          // Формирование полусферы (3 сек)
    SAFE_ZONES_APPEARING,          // Появление безопасных зон
    FINAL_PREPARATION,             // Финальная подготовка (1 сек)
    HEMISPHERE_ATTACK,             // Атака полусферой
    COOLDOWN                       // Откат спецатаки
}
```

### Параметры безопасных зон

- **Количество**: `Math.min(количество_игроков + 1, 6)` (максимум 6 зон)
- **Размер**: 3.5-4 блока радиус (увеличено для лучшей доступности)
- **Форма**: Круглая
- **Визуализация**: Светящиеся частицы и отметки на земле с предупреждающими индикаторами
- **Длительность**: Постоянные в течение фазы атаки
- **Динамическое масштабирование**: Для одного игрока - увеличенный радиус 4 блоков

### Визуальные эффекты

- **Подъем черепов**: Плавное поднятие из земли с эффектами частиц
- **Формирование полусферы**: Визуальное создание сферической структуры
- **Безопасные зоны**: Яркая световая индикация границ
- **Атака**: Одновременный запуск всех черепов

## Validation Criteria

- [ ] Босс правильно выполняет все фазы новой анимации
- [ ] Черепа эффектно поднимаются из земли и формируют полусферу
- [ ] Безопасные зоны появляются в правильном количестве и местах
- [ ] Игроки могут определять и использовать безопасные зоны
- [ ] Атака наносит корректный урон игрокам вне безопасных зон
- [ ] Производительность остается приемлемой
- [ ] Нет багов с застреванием босса или черепов

## Rollback Plan

2. Сохранить обратную совместимость с существующими конфигурациями
3. Добавить опцию включения/выключения новой механики
