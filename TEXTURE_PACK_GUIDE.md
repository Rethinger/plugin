## Технические требования

### Разрешения текстур
- **Предметы**: 16x16 пикселей (стандарт), можно 32x32 для HD
- **Эффекты**: 16x16 или 32x32 пикселей
- **Иконка текстурпака**: 64x64 пикселей

### Форматы файлов
- **Текстуры**: PNG с прозрачностью
- **Модели**: JSON файлы для 3D моделей
- **Анимации**: PNG файлы с кадрами или файлы .mcmeta для анимации

### Палитра цветов
Рекомендуется использовать тёмную, мистическую палитру:
- **Фиолетовые/синие** для магических предметов
- **Тёмно-серые/чёрные** для предметов тьмы
- **Оранжевые/красные** для огненных предметов
- **Зелёные** для некромантии
- **Белые/серебристые** для божественных предметов

## Интеграция с плагином

### CustomModelData для предметов
Плагин использует CustomModelData для применения кастомных текстур:

```java
// Пример из плагина
ItemStack item = new ItemStack(Material.DIAMOND_SWORD);
ItemMeta meta = item.getItemMeta();
meta.setCustomModelData(1001); // ID для кастомной модели
meta.setDisplayName("§6Лордский меч");
item.setItemMeta(meta);
```

### Требуемые CustomModelData значения
- `1001-1010`: Предметы Акт 1
- `1011-1020`: Предметы Акт 2
- `1021-1030`: Предметы Акт 3 (Скелет-лорд)
- `1031-1040`: Предметы Акт 4 (Властелин Ифрита)
- `1041-1050`: Предметы Акт 5 (Босс Эндермен)
- `1051-1060`: Эффекты и частицы
- `1061-1070`: Прочие предметы

## Процесс создания

### 1. Подготовка
1. Создайте папку `texture-pack/`
2. Создайте файл `pack.mcmeta`
3. Подготовьте изображения иконки `pack.png`

### 2. Создание текстур
1. Нарисуйте базовые текстуры предметов в PNG
2. Создайте вариации для разных состояний (если нужно)
3. Протестируйте текстуры в игре

### 3. Создание моделей
1. Создайте JSON файлы моделей в `assets/minecraft/models/item/`
2. Настройте parent и texture для каждой модели
3. Свяжите текстуры с CustomModelData

### 4. Локализация
1. Создайте файлы локализации в `assets/minecraft/lang/`
2. Добавьте названия для всех кастомных предметов

### 5. Тестирование
1. Упакуйте текстурпак в ZIP архив
2. Протестируйте в игре с плагином
3. Проверьте все предметы и эффекты

## Советы по дизайну

### Стиль текстур
- Используйте consistent стиль для всех предметов одного акта
- Предметы боссов должны выглядеть более детализированными и мощными
- Артефакты должны иметь магическое свечение на текстурах

### Цветовая схема
- **Акт 1**: Синие/фиолетовые тона (магия и стабильность)
- **Акт 2**: Оранжевые/красные тона (огонь и энергия)
- **Акт 3**: Серые/фиолетовые тона (некромантия и тьма)
- **Акт 4**: Красные/жёлтые тона (огонь и мощь)
- **Акт 5**: Чёрные/фиолетовые тона (энд и телепортация)

### Анимация
- Для важных предметов добавьте анимированные текстуры
- Эффекты должны иметь плавные переходы
- Боссовые предметы могут иметь пульсирующие анимации
